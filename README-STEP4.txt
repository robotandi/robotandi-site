Step 4 package: privacy page, sitemap, robots.txt, 404 page, share image.

1. Install the sitemap integration (one time):
     npm install @astrojs/sitemap
2. Unzip over your project (this zip does NOT include src/config.ts, so your form key is safe).
3. npm run dev, then check /ar/privacy/, /en/privacy/ and a missing page like /ar/nothing/.
4. Branch, commit, push, pull request, check the preview, merge.
